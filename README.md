# بات دانشجویی ثبت واژگان

بات تلگرامی .NET 10 با SQLite که دانشجو با شماره دانشجویی ثبت‌نام می‌کند و واژگان را از طریق فرم مرحله‌ای وارد می‌کند. برنامه فقط در زمان اجرا و اتصال به Telegram Bot API پاسخ می‌دهد.

## راه‌اندازی محلی

با BotFather بات بسازید و در PowerShell اجرا کنید:

```powershell
$env:BOT_TOKEN = 'توکن بات'
$env:BOT_ADMIN_ID = 'شناسه عددی تلگرام ادمین'
dotnet run --project VocabularyBot.Bot
```

توکن محرمانه است و نباید در مخزن یا گفتگو منتشر شود. `BOT_ADMIN_ID` شناسه عددی تلگرام ادمین اولیه است؛ پس از `/start`، ادمین می‌تواند نقش ادمین را به کاربران دیگر بدهد. کاربران در گفت‌وگوی خصوصی `/start` را می‌فرستند. برای توقف برنامه Ctrl+C را بزنید. اگر قبلاً webhook تنظیم شده باشد، باید آن را از طریق Bot API حذف کنید تا long polling کار کند.

تنظیمات پیش‌فرض در `VocabularyBot.Bot/appsettings.json` قرار دارند. برای محیط توسعه، با تنظیم `DOTNET_ENVIRONMENT=Development`، مقادیر `appsettings.Development.json` نیز بارگذاری می‌شوند. کلیدهای `Bot:Token`، `Bot:AdminId` و `Bot:DataDirectory` قابل تنظیم‌اند؛ متغیرهای `BOT_TOKEN`، `BOT_ADMIN_ID` و `BOT_DATA_DIR` بر آن‌ها اولویت دارند. توکن را در فایل‌های متعهدشده به مخزن قرار ندهید و برای آن از متغیر محیطی استفاده کنید.

برای تعیین ادمین اولیه با نام کاربری، `Bot:AdminUsername` یا متغیر `BOT_ADMIN_USERNAME` را تنظیم کنید. هنگام ارسال `/start`، اگر هنوز ادمینی وجود نداشته باشد، حسابی با آن نام کاربری ادمین می‌شود؛ نام کاربری با یا بدون `@` و بدون حساسیت به بزرگی حروف پذیرفته می‌شود.

در ساخت Debug، اگر محیط به‌صورت صریح مشخص نشده باشد، برنامه به‌طور پیش‌فرض از محیط Development استفاده می‌کند. در ساخت Release، محیط پیش‌فرض Production است. با `DOTNET_ENVIRONMENT` می‌توانید محیط را صریحاً تعیین کنید.

دیتابیس در `%LOCALAPPDATA%\VocabularyBot\vocabulary.db` ایجاد و migrationها هنگام اجرا اعمال می‌شوند. برای تعیین پوشه دیگر، متغیر `BOT_DATA_DIR` را تنظیم کنید. پیش از ارتقا برنامه را متوقف و از فایل دیتابیس پشتیبان تهیه کنید.

## استقرار با systemd

اگر سرور لینوکس از قبل runtime نسخه ۱۰ دات‌نت را دارد، فایل `deploy/vocabularybot.service` برای اجرای دائمی بات آماده است. خروجی `dotnet publish` در حالت Release را در `/opt/vocabularybot/releases/<release>` قرار دهید و symlink مسیر `/opt/vocabularybot/current` را به آن متصل کنید.

سرویس از کاربر سیستمی `vocabularybot`، پوشه دیتابیس `/var/lib/vocabularybot` و فایل تنظیمات `/etc/vocabularybot/bot.env` استفاده می‌کند. فایل تنظیمات باید متعلق به root و با دسترسی `600` باشد و شامل `BOT_TOKEN` و `BOT_ADMIN_ID` یا `BOT_ADMIN_USERNAME` باشد. فایل سرویس را در `/etc/systemd/system/` نصب کنید و اجرا کنید:

```sh
sudo systemctl daemon-reload
sudo systemctl enable --now vocabularybot
sudo systemctl status vocabularybot --no-pager
sudo journalctl -u vocabularybot -n 100 --no-pager
```

برای راه‌اندازی مجدد از `sudo systemctl restart vocabularybot` استفاده کنید. پیش از ارتقا سرویس را متوقف و از دیتابیس پشتیبان تهیه کنید. داده‌ها خارج از پوشه انتشار باقی می‌مانند.

اگر Mihomo روی همان سرور با پورت `127.0.0.1:7890` اجرا می‌شود، فایل `deploy/proxy.conf` را در `/etc/systemd/system/vocabularybot.service.d/proxy.conf` قرار دهید و سپس `sudo systemctl daemon-reload` و `sudo systemctl restart vocabularybot` را اجرا کنید. HttpClient برنامه متغیرهای پروکسی سرویس را استفاده می‌کند. قانون عبور مستقیم IPهای ایران باید در Mihomo تنظیم شود؛ `NO_PROXY` بالا فقط آدرس‌های loopback را مستثنا می‌کند.

## استقرار با Docker

روی سرور لینوکسی با Docker Engine و افزونه Compose، فایل `.env.example` را به `.env` کپی کنید و توکن و شناسه یا نام کاربری ادمین اولیه را در آن قرار دهید. دسترسی فایل را با `chmod 600 .env` محدود کنید. سپس اجرا کنید:

```sh
docker compose up -d --build
docker compose logs --tail=100 bot
docker compose ps
```

بات در محیط Production و با کاربر غیر root اجرا می‌شود. نیازی به باز کردن پورت ورودی ندارد؛ اتصال خروجی به Telegram Bot API لازم است. فقط یک نمونه از بات با هر توکن اجرا کنید. فایل تنظیمات توسعه و دیتابیس محلی وارد image نمی‌شوند.

دیتابیس در volume دائمی `bot-data` نگهداری می‌شود و با تعویض کانتینر باقی می‌ماند. برای ارتقا، ابتدا بات را متوقف و از دیتابیس پشتیبان تهیه کنید:

```sh
docker compose stop bot
mkdir -p backups
docker compose cp bot:/data/vocabulary.db "backups/vocabulary-$(date +%Y%m%d-%H%M%S).db"
docker compose up -d --build
```

فرمان `docker compose down -v` داده‌ها را حذف می‌کند؛ برای توقف عادی از `docker compose stop` استفاده کنید. سرویس Docker باید هنگام روشن شدن سرور فعال شود تا سیاست `restart` بات را دوباره اجرا کند.

## استفاده

منوی فارسی پایین گفتگو، کارهای اصلی را بدون تایپ دستور در دسترس قرار می‌دهد. گزینه‌های مدیریت فقط برای ادمین نمایش داده می‌شوند. داخل فرم، دکمه‌ها متناسب با مرحله تغییر می‌کنند: برگشت، لغو، رد کردن مترادف و ثبت نهایی.

کلاس‌ها با نام دانشگاه، سال و ترم روی دکمه نمایش داده می‌شوند؛ نیازی به کپی شناسه نیست. فهرست در صفحه‌های ۸تایی نمایش داده می‌شود و برای ثبت واژه فقط کلاس‌هایی که عضو آن‌ها هستید قابل انتخاب‌اند. دکمه‌های فرم قبلی پس از شروع فرم جدید غیرفعال می‌شوند.

- `/start`: شروع، ثبت شماره دانشجویی و سپس انتخاب کلاس از فهرست؛ شماره فقط شامل رقم است و ارقام فارسی و عربی پذیرفته می‌شوند.
- `/register`: ثبت یا تغییر شماره دانشجویی؛ یک شماره نمی‌تواند متعلق به دو حساب باشد.
- `/classes`: فهرست کلاس‌ها؛ ادمین همه کلاس‌ها و دانشجو کلاس‌های خودش را می‌بیند.
- `/course`: ادمین دانشگاه، سال و شماره ترم را وارد می‌کند و کلاس می‌سازد.
- `/join`: انتخاب کلاس از فهرست و عضویت مستقیم؛ برای عضویت در کلاس‌های دیگر نیز از همین دستور استفاده کنید.
- `/admin`: ادمین با شناسه تلگرام یا نام کاربری، به کاربر ثبت‌نام‌شده نقش ادمین می‌دهد.
- `/word`: کلمه یا عبارت انگلیسی، تلفظ، معنی فارسی و خانواده واژه اجباری‌اند؛ مترادف و ترجمه‌های اختیاری به زبان‌های آلمانی، فرانسوی و اسپانیایی پشتیبانی می‌شوند. در مرحله ترجمه هر تعداد خط با قالب «زبان: ترجمه» بفرستید (مانند «آلمانی: Beispiel») برای اصلاح ترجمه، همان زبان را با مقدار جدید دوباره بفرستید و برای پایان `/done` را ارسال کنید. برای رد کردن فیلد اختیاری `/skip` را بفرستید. اگر عضو چند کلاس باشید ابتدا کلاس واژه را انتخاب می‌کنید.
- `/words`: مشاهده واژه‌های ثبت‌شده خودتان.
- `/back`: برگشت به مرحله قبل در فرم واژه یا ساخت کلاس؛ پاسخ آن مرحله را دوباره وارد کنید. برگشت از مرحله ترجمه، مترادف و ترجمه‌های پیش‌نویس را پاک می‌کند تا دوباره وارد شوند.
- `/cancel`: لغو فرم و بازگشت به منو.
- `/menu`: خروج از فرم فعلی و نمایش منوی اصلی؛ اطلاعات فرم تکمیل‌نشده کنار گذاشته می‌شود.
- `/help`: راهنما بدون خروج از فرم فعلی.

عنوان انگلیسی با حذف تفاوت فاصله و حروف بزرگ و کوچک مقایسه می‌شود و در کل بات تکراری پذیرفته نمی‌شود. هر ترجمه به‌صورت یک entity با نوع زبان enum و یک مقدار جدا ذخیره می‌شود؛ برای وارد کردن چند زبان در یک پیام، هر ترجمه را در خطی جداگانه بنویسید. برای پشتیبانی از زبان جدید، مقدار و نام نمایشی آن را به LanguageType اضافه کنید.

دانشجویان هنگام ثبت‌نام کلاس خود را از فهرست انتخاب و مستقیماً عضو آن می‌شوند.

## آزمون

```powershell
dotnet test VocabularyBot.slnx
```

پروژه لایه‌های Domain، Application و Infrastructure، الگوی CQRS با MediatR و Generic Repository دارد. آزمون‌ها از SQLite واقعی استفاده می‌کنند؛ اتصال زنده به تلگرام نیازمند توکن و آزمایش جداگانه است.

رابط تلگرام از [ReplyKeyboardMarkup و InlineKeyboardMarkup در Bot API](https://core.telegram.org/bots/api#replykeyboardmarkup) استفاده می‌کند. برای بررسی دستی، ثبت‌نام، انتخاب کلاس، ثبت واژه با دکمه‌ها، برگشت به مرحله قبل، لغو فرم و انتخاب دوباره دکمه یک فرم قدیمی را در گفتگوی خصوصی امتحان کنید.
