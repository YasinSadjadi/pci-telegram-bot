# بات دانشجویی ثبت واژگان

بات تلگرامی .NET 10 با SQLite که دانشجو با شماره دانشجویی ثبت‌نام می‌کند و واژگان را از طریق فرم مرحله‌ای وارد می‌کند. برنامه فقط در زمان اجرا و اتصال به Telegram Bot API پاسخ می‌دهد.

## راه‌اندازی محلی

با BotFather بات بسازید و در PowerShell اجرا کنید:

```powershell
$env:BOT_TOKEN = 'توکن بات'
$env:BOT_ADMIN_ID = 'شناسه عددی تلگرام ادمین'
dotnet run --project VocabularyBot.Bot
```

توکن محرمانه است و نباید در مخزن یا گفتگو منتشر شود. `BOT_ADMIN_ID` شناسه عددی تلگرام ادمین اولیه است؛ پس از `/start`، ادمین می‌تواند نقش ادمین را به کاربران دیگر بدهد. کاربران در گفت‌وگوی خصوصی `/start` را می‌فرستند. برای توقف برنامه Ctrl+C را بزنید. اگر قبلاً webhook تنظیم شده باشد، باید آن را از طریق Bot API حذف کنید تا long polling کار کند.

دیتابیس در `%LOCALAPPDATA%\VocabularyBot\vocabulary.db` ایجاد و migrationها هنگام اجرا اعمال می‌شوند. برای تعیین پوشه دیگر، متغیر `BOT_DATA_DIR` را تنظیم کنید. پیش از ارتقا برنامه را متوقف و از فایل دیتابیس پشتیبان تهیه کنید.

## استفاده

- `/start`: شروع، ثبت شماره دانشجویی و سپس انتخاب کلاس از فهرست؛ شماره فقط شامل رقم است و ارقام فارسی و عربی پذیرفته می‌شوند.
- `/register`: ثبت یا تغییر شماره دانشجویی؛ یک شماره نمی‌تواند متعلق به دو حساب باشد.
- `/classes`: فهرست کلاس‌ها؛ ادمین همه کلاس‌ها و دانشجو کلاس‌های خودش را می‌بیند.
- `/course`: ادمین دانشگاه، سال و شماره ترم را وارد می‌کند و کلاس می‌سازد.
- `/join`: انتخاب کلاس از فهرست و عضویت مستقیم؛ برای عضویت در کلاس‌های دیگر نیز از همین دستور استفاده کنید.
- `/admin`: ادمین با شناسه تلگرام یا نام کاربری، به کاربر ثبت‌نام‌شده نقش ادمین می‌دهد.
- `/word`: ابتدا شناسه کلاس عضوشده و سپس کلمه یا عبارت انگلیسی، تلفظ و معنی فارسی که اجباری‌اند؛ سپس خانواده، مترادف‌ها و ترجمه به زبان‌های دیگر که اختیاری‌اند. برای رد کردن فیلد اختیاری `/skip` را بفرستید.
- `/words`: مشاهده واژه‌های ثبت‌شده خودتان.
- `/cancel` و `/help`: لغو فرم و نمایش راهنما.

عنوان انگلیسی با حذف تفاوت فاصله و حروف بزرگ و کوچک مقایسه می‌شود و در کل بات تکراری پذیرفته نمی‌شود. ترجمه‌های دیگر به صورت متن آزاد، مثلاً «آلمانی: Beispiel، اسپانیایی: ejemplo»، وارد می‌شوند.

کلاس‌ها فعال‌اند و مفهوم گروه در مسیر کاربری وجود ندارد؛ دانشجویان هنگام ثبت‌نام کلاس خود را از فهرست انتخاب و مستقیماً عضو آن می‌شوند. در مهاجرت، عضویت‌های قدیمی گروه به عضویت مستقیم کلاس تبدیل می‌شوند. جدول‌های قدیمی و اطلاعات آن‌ها برای جلوگیری از حذف داده حفظ شده‌اند؛ واژه‌های قدیمی به‌دلیل نداشتن تلفظ وارد فرم جدید نمی‌شوند اما عنوانشان در بررسی تکراری بودن واژه‌های جدید لحاظ می‌شود. کاربران قدیمی باید شماره دانشجویی خود را ثبت کنند.

## آزمون

```powershell
dotnet test VocabularyBot.slnx
```

پروژه لایه‌های Domain، Application و Infrastructure، الگوی CQRS با MediatR و Generic Repository دارد. آزمون‌ها از SQLite واقعی استفاده می‌کنند؛ اتصال زنده به تلگرام نیازمند توکن و آزمایش جداگانه است.
